# Acceso privado para expertos

El propietario puede abrir **Settings → Collaborators → Add people**, buscar el usuario GitHub confirmado y enviar acceso con el permiso mínimo que permita revisar los materiales. Revisar los accesos concedidos al cerrar la evaluación. Cada persona debe aceptar su invitación y acceder al repositorio y a la prerelease con su cuenta. No se han enviado invitaciones como parte de esta publicación.
